# Operon 候选选择验证计划

本计划在新实验的第一次 API 选择前固定。基于旧三套题、两种 SR 的筛选，选取 Taillard 及 Operon。本轮恰好两项正式比较，同时报告，所有实例等权。
1. Taillard 全 120 题更换随机种子；OR-Library flowshop1 全 31 题验证跨实例集迁移。两边用 101、131、173 三个种子。已测题的重复与新题分开报告。
2. 同一历史提示、模型、候选生成器及目标评分器。DeepSeek 无 SR、DeepSeek + Operon 预测和公式并行比较。每题每种子有12个同一起点，每轮8选1，再真实评分12次。Operon直接选最低预测作次要描述性对照。
3. 主要终点：每个同题同种子对的最终实际工期缩短比例 100*(历史-SR)/历史。每题先平均三个种子，再等权平均全套题。正值代表 SR 改善。显著性的操作定义：实例级配对符号翻转检验（双侧，199999次蒙特卡洛，随机种子20261125，plus-one校正），两项主比较按 Holm 控制0.05，均值需为正。同时报告实例级重抽样95%区间、配对胜平负及工程量级。区间未作多重调整。固定样本，不在中途看结果选停点。随机化推断的符号可交换性及对其他题集的外推均有限；三次重复不视作独立题目。
4. “仅历史”能看到题目描述、候选特征、最好与最近两条已测记录；仅有 SR 的组额外看到预测与公式。SR 用全部已测记录拟合。此次检验整套信息增益；不能隔离是公式文本还是数值预测起作用。公开参考值不参与选择和主要统计。
补充敏感性检查（在读取任何新组成绩之前确定）：OR-Library 全31题另跑两组，双方每轮都能看到该条轨迹从第一条开始的全部已测特征与目标值，SR组额外得到Operon预测与公式。实例、种子、候选算子和查询次数均保持一致。单列描述性差异和实例级95%区间，不用它替换两项主要检验、触发停止或追加尝试。
